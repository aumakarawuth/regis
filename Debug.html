❌ 400 Bad Request → URL ผิด / GAS ยังไม่ได้ deploy / CORS header

❌ 401 Unauthorized → token admin ผิด

❌ CORS Error → ส่ง Content-Type: application/json → ทำให้เกิด preflight → GAS ปฏิเสธ

✅ วิธีแก้ POST → ไม่ใส่ Content-Type header ใน fetch()

✅ Deploy ใหม่ทุกครั้งที่แก้โค้ด GAS → "New deployment" ไม่ใช่ redeploy
